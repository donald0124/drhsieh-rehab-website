# Poster Skill — 診所 A3 海報製作流程

## 觸發情境
- 「把這篇文章做成海報」
- 「幫我做一張 A3 海報」
- 「做成海報 / 生成海報 / 出一張海報」
- 使用者指定文章路徑或 slug 後說「海報」

## 執行流程（共五步，**不可跳過**）

---

### STEP 1 — 讀取文章

讀取使用者指定的文章（Markdown 或任何格式）。

- 若使用者只說文章名稱或 slug，從 `src/content/blog/` 找對應 `.md` 檔
- 完整讀取全文，理解：主題、核心主張、目標讀者、關鍵數據或名詞

---

### STEP 2 — 提案海報文字內容

根據文章內容，提出以下結構，**以表格或清單列出，讓使用者一目瞭然**：

| 區塊 | 提案內容 | 說明 |
|------|----------|------|
| 主標題 | （1句，≤15字，遠距可讀，引發共鳴） | 最大字，決定是否停下來看 |
| 副標題 | （1句，補充說明主標題） | 稍小字 |
| 治療/主題名稱 | （中文全名 + 英文縮寫 + 英文全名） | 突顯專業性 |
| 核心重點 | 3 條，每條 ≤20 字 | 簡短有力，遠距讀 |
| 症狀帶 | 橫排，6–10 項常見症狀，用「・」或空格分隔 | 讓患者對號入座 |
| CTA | 掃描 QR Code + 1句說明文字 | QR code 連結到指定 URL |
| 底部署名 | **永遠留空**，不放診所名稱 | 使用者自行印製時加上 |

**選字原則：**
- 患者不需要醫學背景也能看懂
- 避免術語堆砌，優先選日常用語
- 症狀帶挑選「患者自己能對號入座」的，略去罕見或需解釋的診斷名

---

### STEP 3 — 與使用者討論，可提問

提案完畢後，**主動詢問以下確認項目**（若使用者未主動說明）：

1. QR Code 連結網址（預設：`https://drhsieh-rehab.com/blog/<slug>/`）
2. A3 直式 or 橫式（預設：**直式**）
3. 色調偏好：深色系（深藍/黑）或淺色系（白/灰），或參考圖
4. 主視覺意象：有無偏好（人體示意圖、剖面圖、抽象光點、醫療器械等）

> **固定預設（不需詢問）：** 底部不放診所名稱、電話、LINE，一律留空。

每次修改文字後，重新列出完整確認清單，讓使用者一次核對。

---

### STEP 4 — 等待使用者明確確認

**在使用者說出「OK」「可以」「確認」「生成」等明確同意語句前，不可進入 STEP 5。**

若使用者只修改部分內容，更新後再次列出完整清單並請求確認。

---

### STEP 5 — 呼叫 draw 生成低畫質初稿

確認後，組合 prompt 並呼叫 draw 腳本：

```bash
python "C:/Users/Lee/.claude/skills/draw/draw.py" \
  "<完整英文 prompt>" \
  --size 1024x1536 \
  --quality low \
  --name <article-slug>-poster
```

**Prompt 組合規則：**
- 以英文撰寫（圖像生成效果較佳）
- 中文文字直接內嵌於 prompt（圖中會顯示）
- 明確描述：背景色調、版面分區、字體層次、主視覺風格、各區塊位置
- 結尾加：`Style: clean professional medical poster, high contrast for readability at distance, generous whitespace.`

**固定參數：**
- `--size 1024x1536`（A3 直式；若使用者選橫式改為 `1536x1024`）
- `--quality low`（初稿永遠 low，確認後使用者再決定是否升畫質）
- `--name` 使用文章 slug 加 `-poster`

**生成後：**
1. 顯示圖片給使用者
2. 提醒：「圖中 QR code 為裝飾佔位，需在設計軟體中替換成真實可掃描的 QR code」
3. 詢問：是否需要調整，或升為 `high` 畫質生成最終版

---

## 注意事項

- 整個流程要**對話式進行**，不要一次輸出大量內容讓使用者應付不來
- STEP 2 提案後，等使用者回應再繼續
- 若使用者提供參考圖片，描述其視覺風格並融入 prompt
- 資訊不塞太滿：海報主要靠「主標題 + 視覺」吸引注意，細節引導掃碼閱讀
- 字體層次：主標題 > 治療名稱 > 核心重點 > 症狀帶 > CTA，層次不超過 5 級
