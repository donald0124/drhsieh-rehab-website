# 部落格文章建立 Skill — 謝明福復健科

## 重點結論（LLM 先讀這裡）

1. **先問 brief，再動筆**：一次問完所有問題後，等使用者回覆才開始寫。
2. **掃描現有文章**：讀取 `src/content/blog/` 全部 frontmatter，選出 2-3 篇最相關的作為站內連結，並確認無重複主題。
3. **核心固定、中間彈性**：「重點結論」「情境帶入」「治療方式」「醫療聲明」四個核心段落必須存在；中間段落（FAQ、誰適合看、何時就醫、鑑別診斷、自我檢視、臨床思路、預防照護、結語）依主題自由組合，不必每篇都全上。
4. **GEO 三原則**：① 重點結論放最前，3 條短句直接給答案 ② FAQ（若有）先答後理由 ③ 每個段落開頭先結論再展開。
5. **寫入 `blogdrafts/[slug].md`**（暫存草稿），再輸出人工確認清單。確認後再由使用者移入 `src/content/blog/` 發布。

---

## 觸發情境

- 「寫一篇關於 [症狀] 的文章」
- 「幫我寫 [治療] 的衛教文章」
- 「新增一篇部落格」
- 使用者描述某個症狀或治療主題後說「文章」「衛教」「寫一篇」

---

## 步驟一：收集 Brief

**一次全問，不要分開問**：

> 請告訴我以下資訊，我就可以開始撰寫：
>
> 1. **主題**：這篇文章要介紹什麼？（症狀名稱、治療方式，一句話）
> 2. **目標讀者**：主要對象是誰？（例：久坐上班族、銀髮族、運動員、產後婦女、術後患者）
> 3. **治療重心**：要強調哪種治療方向？（一般復健 / NEIMS / Superlizer / 注射治療 / 不特定）
> 4. **特別重點**（可選）：有沒有特別想強調的臨床觀點、常見患者迷思、或衛教上容易說不清楚的地方？

收到回覆後，進入步驟二。

---

## 步驟二：研究與規劃

### 2.1 掃描現有文章

讀取 `src/content/blog/` 目錄下所有 `.md` 檔案的 frontmatter（title + tags + category）。

**目的一：防重複**
若已有高度相似主題的文章，告知使用者並詢問：
- 是否繼續（角度差異化）？
- 還是改成更新既有文章？

**目的二：選內鏈目標**
從現有文章中選出 2-3 篇最相關的，作為「延伸閱讀與就醫資訊」段落的連結目標。

內鏈選取優先順序：
1. **同症狀群**：例如腰痛主題 → 優先選坐骨神經痛、脊椎保護、腸薦關節等文章
2. **同治療方式**：若文章介紹 NEIMS → 優先選 `neims.md`、`neims-first-visit.md`
3. **同讀者族群**：例如高齡主題 → 優先選 `neims-for-senior.md`、`neims-sciatica-elderly.md`
4. **避免強連**：足踝主題別連到肩頸，主題距離太遠反而傷害 UX

### 2.2 決定 Slug

Slug 規則：
- 全英文小寫，以 `-` 連接，3-6 個詞為宜
- 描述主要症狀或治療，不加診所名、不加地名
- NEIMS 相關文章：症狀在前 → `[condition]-neims`；NEIMS 特定面向 → `neims-[aspect]`
- 現有範例參考：`runner-knee`、`frozen-shoulder`、`sacroiliac-joint-pain`、`neims-first-visit`、`plantar-fasciitis-heel-pain`

### 2.3 決定 Category

| 選擇 | 適用情境 |
|------|---------|
| `['特色治療']` | 文章核心是 NEIMS、Superlizer、玻尿酸注射、葡萄糖水增生注射、星狀神經節（SGB） |
| `['復健衛教']` | 症狀說明、病因分析、生活衛教、鑑別診斷、運動傷害、術後復健、骨質疏鬆、姿勢問題等 |

### 2.4 產出 Tags 清單（6-10 個）

組合以下類型：

| 類型 | 範例 | 說明 |
|------|------|------|
| 症狀關鍵字 | `'腸薦關節痛'`、`'下背痛'` | 最主要的 2-3 個 |
| 解剖部位 | `'腸薦關節'`、`'SIJ'` | 可加英文縮寫 |
| 治療關鍵字 | `'NEIMS'`、`'Superlizer'`、`'直線偏極光治療'` | 涉及哪種治療就加 |
| **在地詞（必加）** | `'三峽復健'`、`'鶯歌復健'`、`'新北復健'` | 每篇至少 1 個 |
| 讀者族群（選加）| `'銀髮族'`、`'運動員'`、`'上班族'` | 視主題加 |
| 內容特色（選加）| `'院長經驗談'`、`'鑑別診斷'`、`'衛教文章'` | 視內容加 |

## 步驟三：撰寫完整草稿

### 3.1 Frontmatter 格式

```yaml
---
title: '[症狀/治療主題完整描述]｜謝明福復健科'
description: '[60-90字。直接說明症狀、核心原因、治療方向、讀者收穫。含三峽或鶯歌等在地詞。]'
pubDate: [今天日期 YYYY-MM-DD]
updatedDate: [今天日期 YYYY-MM-DD]
heroImage: /images/blog/[slug]-hero.jpg
author: '謝明福 院長'
featured: false
category: ['[根據 2.3 規則決定]']
tags: ['[根據 2.4 產出的 tags，逗號分隔]']
---
```

**Description 寫法**：一句話說明症狀 + 一句話說明文章解決什麼 + 在地詞。
範例：「腸薦關節痛的症狀與腰椎問題高度相似，需要詳細的理學檢查才能找到正確治療方向。謝明福醫師深入解析腸薦關節解剖、疼痛機制與鑑別診斷，幫助三峽與鶯歌患者找到真正的疼痛根源。」

### 3.2 段落結構：核心固定、中間彈性

#### 核心段落（必須存在，順序固定）

```markdown
## 重點結論                      ← 必須第一個，3 條短句
## [問句或情境式標題]            ← 必須緊接重點結論
   （情境帶入段落）
                                 ← 中間段落視主題組合
## 治療方式                      ← 必須包含，可拆多個 H3 步驟
> **醫療聲明**                   ← 必須最後一個段落
```

#### 中間段落工具箱（視主題選用，不必全上）

| 段落類型 | 適合情境 | 標題範例 |
|---------|---------|---------|
| **定義與解剖** | 多數症狀文章 | `## [主題]是什麼？為什麼會發生？` |
| **鑑別診斷表格** | 症狀容易混淆的主題 | `## [A] vs [B] vs [C]：症狀與位置的混淆` |
| **誘發因素清單** | 慢性或生活習慣相關 | `## 六大常見誘發因素` |
| **臨床診斷說明** | 涉及理學檢查的主題 | `## 臨床診斷：理學檢查比影像更關鍵` |
| **臨床思路（院長觀點）** | 症狀容易與其他問題混淆、需要說明診斷複雜性的主題 | `## 臨床思考：理解[主題]的複雜性` |
| **自我檢視清單** | 替代「誰適合看」 | `## 自我檢視：你的疼痛是[主題]嗎？` |
| **何時就醫** | 症狀容易拖延、延誤就醫的主題 | `## 何時應該就醫？` |
| **預防與自我照護** | 生活習慣相關、讀者可立即行動 | `## 預防與自我照護` |
| **常見問題 FAQ** | 有明確患者常問問題、或搜尋意圖明確 | `## 常見問題（FAQ）` |
| **延伸閱讀與就醫資訊** | 無嵌入式連結、或需要集中站內連結 | `### 延伸閱讀與就醫資訊` |
| **結語** | 主題複雜、需要暖場收尾、取代 CTA 區塊 | `## 結語：[有力的結論句]` |

#### 內部連結放置方式（二擇一）

**方式 A：集中放在「延伸閱讀與就醫資訊」**（適合較短的文章）
```markdown
### 延伸閱讀與就醫資訊

- [錨文字描述症狀或決策情境](/blog/slug/)
- [錨文字描述症狀或決策情境](/blog/slug/)
- [有反覆或加重情況，建議先查看門診時間與就診資訊](/#patient-info)
```

**方式 B：嵌入在治療步驟內**（適合內容較深、治療方式分步說明的文章）
```markdown
### 第一步：[治療方式名稱]

**[直線偏極光治療（Superlizer）](/treatments/superlizer/)**

...說明...

[了解直線偏極光治療（Superlizer）的原理與應用 →](/blog/superlizer/)
```

兩種方式可混用：治療步驟嵌入連結，文末仍可加「延伸閱讀」，但不強制。

### 3.3 各段落寫作規則

#### 重點結論

- **位置**：緊接在 frontmatter 後，第一個 H2
- **格式**：3 條 bullet，每條 1-2 句
- **原則**：直接給答案，不鋪陳背景。提供 AI 摘要可直接引用的精煉句子
- **範例**：
  ```markdown
  ## 重點結論

  * 腸薦關節（SIJ）位於脊椎底部與骨盆交接處，一旦失穩或發炎，會產生難以定位的下背痛；其症狀與腰椎椎間盤突出、坐骨神經痛高度相似，需透過完整的理學檢查才能鑑別。
  * 影像檢查（X 光或 MRI）常無法呈現腸薦關節的問題；精準診斷依賴理學檢查，而非影像報告。
  * 治療核心在於消除關節發炎並喚醒深層穩定肌，再輔以動作矯正，才能從根本解決骨盆不穩。
  ```

#### 情境帶入段落（重點結論之後、主體說明之前）

**目的**：讓讀者在 2-3 段內產生「這說的就是我」的共鳴，再自然帶出病名或主題，降低資訊焦慮、增加往下讀的動機。

**H2 標題**：用**問句**或**情境描述句**，直接反映患者最常說的話，而不是病名：
- 正確：「膝蓋內側隱隱作痛，甚至出現「軟腳」感？」
- 正確：「手指麻木一定是頸椎長骨刺嗎？」
- 正確：「你的腰痛，真的是腰的問題嗎？」
- 避免：「鵝掌足滑囊炎介紹」（病名直接當標題，無情境代入）

**段落結構（2-3 段）**：

1. **第一段：症狀情境描述**
   - 描述患者的具體感受，使用日常語言（「起床時」「久坐站起」「爬樓梯時」）
   - 可用問句收尾引發讀者自我核對（「您是否也有這樣的困擾？」）

2. **第二段：患者常見的認知困境**
   - 描述患者自己的猜測或嘗試（「以為只是關節退化」「擔心是中風」「試過熱敷、貼藥布但沒改善」）
   - 這段描述的是**患者的主觀經驗與焦慮**，不是評論前次就醫或指其他醫師判斷錯誤
   - 禁用「之前的治療方向錯誤」「被診斷成 A 但其實是 B」等可能暗示誤診的句式

3. **第三段：帶出主題核心（以粗體呈現病名/核心概念）**
   - 揭示真正的病因或解決方向，並在第一次出現時加粗體 + 括號說明英文
   - 例：「這就是臨床上常見的 **「鵝掌足滑囊炎」（Pes Anserine Bursitis）**。」

**範例一（膝蓋內側痛）**：
```markdown
## 膝蓋內側隱隱作痛，甚至出現「軟腳」感？

您是否常覺得膝蓋內側下方有一個說不出的痛點？特別是在早上起床、久坐站起，或是爬樓梯的時候疼痛感特別明顯？有時候在活動時，甚至會感到膝蓋無力、不穩定，出現「軟腳」的感覺？

許多患者遇到這種情況，第一反應是「是不是關節退化了？」——但反覆做熱敷、貼藥布，症狀卻時好時壞，始終找不到根源。

如果您有上述困擾，且按壓膝蓋內側脛骨上方有明顯痛點，您可能遇到的不是一般的關節退化，而是 **「鵝掌足滑囊炎」（Pes Anserine Bursitis）** 找上門了。
```

**範例二（腰痛非腰椎）**：
```markdown
## 你的腰痛，真的是腰的問題嗎？

許多長期受腰痛困擾的患者，做過腰椎牽引、推拿，MRI 也顯示有「輕微椎間盤突出」，但症狀就是反覆發作、好不徹底。

事實上，**他們的疼痛源頭可能根本不在腰椎，而在連接脊椎與骨盆的「腸薦關節」**。這個關節出問題時，症狀與腰椎病變高度相似，需要透過仔細的理學檢查才能找到真正的疼痛根源。
```

**注意事項**：
- 語氣親切但不誇張，不寫「最嚴重的疼痛」「無法忍受」等誇大情緒
- 不在這段做出診斷承諾（「您一定是 XXX」），保留「可能」「常見於」等措詞
- 段落長度：每段 2-4 句，總長不超過 250 字

#### 主體內容（病因 / 解剖 / 症狀）

- 每個 H3 段落**先給一句結論句**，再展開說明
- 善用表格做鑑別診斷比較（3-5 欄），特別適合「OO vs XX」的主題
- 善用條列描述誘發因素與常見原因
- **醫療縮寫處理**：第一次出現時寫「中文名稱（英文全名, 縮寫）」，之後可單用縮寫
  - 正確範例：「腸薦關節（又稱薦髂關節）（Sacroiliac Joint, SIJ）」
  - 之後可直接寫「SIJ」或「腸薦關節」
- 數字用阿拉伯數字（3 個月、2 週、1 公分），不用中文數字

#### 何時應該就醫？

必須包含以下四個要素：
1. 持續時間門檻（「超過 3 個月未改善」）
2. 影響生活功能（睡眠、工作、行走）
3. 合併危險訊號（麻、無力、腫脹、明顯活動受限）
4. 反覆發作或自行處理（貼布、止痛藥）效果有限

段落底部加醫療提醒框：
```markdown
> 醫療提醒：本文為衛教說明，實際診斷與治療仍需由醫師實際診察評估。
```

#### 治療方式

**寫法 A：三層架構**（適合一般衛教文章）

**第一層：基礎處理與生活調整**
患者自行可做的事：休息、姿勢調整、伸展、輔具、冰熱敷。

**第二層：復健科常見治療**
說明熱療、電療、超音波、牽引、藥物等標準處置，重點說明適用時機，而非只列名稱。

**第三層：進階治療評估**（只在主題相關時寫）
NEIMS、Superlizer、注射治療——說明「適合誰」與「解決什麼問題」，不寫療效保證。

**寫法 B：步驟式治療**（適合多種治療方式組合、邏輯有先後順序的文章）

```markdown
### 第一步：[目標，例如：深層消炎與微循環改善]

**[直線偏極光治療（Superlizer）](/treatments/superlizer/)**

...功效說明（用條列）...

[了解直線偏極光治療（Superlizer）的原理與應用 →](/blog/superlizer/)

### 第二步：[目標，例如：深層肌肉激活與修復]

**[針極肌肉內電刺激（NEIMS）](/treatments/neims/)**

...功效說明（用條列）...

[了解針極肌肉內電刺激（NEIMS）的完整說明 →](/blog/neims/)

### 第三步：[目標，例如：動作與姿勢矯正]

...說明自我訓練或動作教育...
```

**NEIMS / Superlizer 連結規則**：
- 名稱第一次出現時超連結到服務頁：`[針極肌肉內電刺激（NEIMS）](/treatments/neims/)` / `[直線偏極光治療（Superlizer）](/treatments/superlizer/)`
- 步驟式寫法中，各步驟可在說明後加一條指向部落格深度文的 CTA 連結（如 `→` 格式），這不算重複
- FAQ 或延伸閱讀中再次提到可重新加連結

> **醫療法合規**：治療描述只用「有助於」「可協助」「部分患者反應」等詞，不寫「保證」「一定」「完全」「根治」「次就好」。

#### 常見問題 FAQ（選用，3-7 題）

**何時加 FAQ**：有明確的患者常問問題（如「NEIMS 和針灸一樣嗎？」）、或主題有搜尋意圖清楚的長尾字詞。若主題複雜、已有豐富正文，可以省略 FAQ，改用「結語」或「自我檢視」收尾。

格式：
```markdown
**Q：[問題，來自患者真實就醫情境]？**

[1 句直接結論]。[1-3 句補充說明]。
```

好問題類型範例：
- 「NEIMS 和針灸一樣嗎？」
- 「一定要先掛門診才能做復健嗎？」
- 「貼痠痛藥布沒有用，怎麼辦？」
- 「影像報告沒問題，為什麼還這麼痛？」
- 「做復健需要做多久？」（注意：不可承諾次數，可說明「視個別狀況而定，評估進展的關鍵是功能改善，如…」）

避免出現：具體療程次數承諾、「幾次會好」的直接回答、預後百分比。

#### 臨床思考：診斷複雜性說明（選用）

適合：症狀容易與其他問題混淆的主題；幫讀者理解為什麼這個問題需要專業評估、不適合自行判斷。

格式：
```markdown
## 臨床思考：理解[主題]的複雜性

### 為什麼[主題]需要仔細評估？

[說明這個症狀在臨床上的特別之處：例如影像難以呈現、症狀與多種情況相似、需要綜合多項理學檢查才能確認]。

### 哪些情況需要特別留意？

[說明哪些患者情況、病史或症狀組合，在臨床評估時值得進一步仔細排查]。

[列出有助於判斷的評估依據（理學檢查項目、症狀特徵、病史重點）]。
```

寫作原則：
- 主語是**症狀本身的複雜性**，不是「誰容易判斷錯」
- 絕對禁止：「A 容易被誤診為 B」「常被誤診」「診斷盲點」「容易漏診」「傳統治療方向錯誤」
- 安全替代句式：「A 與 B 的症狀有高度相似之處，需透過…鑑別」「若出現…，值得請醫師進一步評估」
- 語氣聚焦在「幫讀者理解複雜性」而非「指出他人的疏失」
- 可列出有助於判斷的理學檢查依據，但不評論過去的診斷或治療是否正確

#### 自我檢視清單（選用）

適合：替代或補充「誰適合看」「何時就醫」的內容，讓讀者主動核對。

格式：
```markdown
## 自我檢視：你的疼痛是[主題]嗎？

若你有以下特徵，建議考慮是否為[主題]：

- [具體可自我觀察的症狀或情境]
- [具體可自我觀察的症狀或情境]
- ...

若符合 3 項以上，建議尋求專業復健科醫師的理學檢查評估。
```

#### 預防與自我照護（選用）

適合：生活習慣明顯影響症狀的主題（姿勢、運動傷害、慢性疼痛）。

結構建議：
1. **日常姿勢提醒**：坐姿、站姿、睡姿等具體指示
2. **簡易自我訓練**：可立即執行的動作（需附「需先獲得醫師認可」說明）
3. **何時該尋求醫療協助**：明確門檻（若已有「何時就醫」段落可省略）

#### 結語（選用）

適合：主題複雜、治療策略需要彈性說明；或取代傳統 CTA 區塊、讓文章結尾更自然。

格式：
```markdown
## 結語：[有力的結論句，例如：找對病灶，才是治本之道]

[1-2 段說明]。若你的狀況較為複雜，治療策略也可彈性調整：

* **[合併情境 A]**：搭配 [相應治療]
* **[合併情境 B]**：需先進行 [調整方向]

若長期症狀反覆、保守治療效果有限，建議由復健科醫師進行完整的理學檢查與評估，找出疼痛的真正根源。
```

**結語絕對禁止的兩類句式**：

1. **禁止指導讀者如何向醫師提問**
   - 禁用：「不妨在就診時主動說：『我的 XXX 有沒有問題？』」
   - 禁用：「可以告訴醫師你有…症狀，這樣比較容易讓診斷切中要害」
   - 原因：指導讀者如何「引導診斷」，隱含對醫師專業的不信任，語氣也很奇怪
   - 正確做法：直接說明症狀特徵，讓讀者知道什麼情況值得就醫，其餘交給醫師判斷

2. **衛教文章禁止邀請掛號或招攬就醫**
   - 禁用：「歡迎預約謝明福院長門診」
   - 禁用：「立即預約」「歡迎來診」「掛號諮詢」「歡迎至本院」
   - 原因：台灣醫療法第 85 條明文規範醫療機構不得以廣告引誘就醫，衛教文章作為公開內容尤其需要謹慎
   - 正確做法：說明什麼情況「建議尋求專科醫師評估」，不點名診所或招攬行為

**NEIMS 在結語中的正確衛教寫法**（當主題與肌肉失衡/深層肌肉相關時可加）：

```markdown
對於反覆發作的 [症狀]，若深層肌肉的激活效果有限，[針極肌肉內電刺激（NEIMS）](/treatments/neims/)
是一個值得評估的進階選項——透過精確的肌肉電刺激，有助於喚醒傳統復健難以觸及的深層肌群，
為後續的動作訓練建立更好的條件。
```

原則：說明 NEIMS 可以解決什麼問題、適合什麼情況，不寫療效保證，不寫「謝院長專長」「本診所提供」等廣告語。

#### 延伸閱讀與就醫資訊（選用）

**什麼時候用**：文章沒有嵌入足夠的站內連結時，補一個集中的連結區塊。若治療步驟已嵌入連結（方式 B），此區塊可省略，或只保留 `/#patient-info` 那條。

**固定標題**（`###` 層級，標題文字一字不改）：
```markdown
### 延伸閱讀與就醫資訊
```

**內鏈格式**（固定用條列，不用引用框、不用 emoji）：
```markdown
- [錨文字描述症狀或決策情境](/blog/[slug]/)
- [錨文字描述症狀或決策情境](/blog/[slug]/)
- [有反覆或加重情況，建議先查看門診時間與就診資訊](/#patient-info)
```

**內鏈規則**：
- 全文（含嵌入式連結）合計至少 2 條站內相關文章連結
- `/#patient-info` 若有獨立區塊則放在最後；若無獨立區塊，可嵌入結語中
- 錨文字描述情境或決策，禁用「了解更多」「點擊這裡」「延伸閱讀」「更多資訊」
- 所有路徑結尾必須有斜線（`/blog/slug/` 而非 `/blog/slug`）

**好錨文字範例**：
- 「高齡坐骨神經痛保守治療可先看這篇」
- 「腰椎牽引沒效可先看坐骨神經痛鑑別」
- 「術後背痛持續可參考肌筋膜沾黏處理」

#### 文末醫療聲明（固定段落，不可省略）

```markdown
> **醫療聲明**
> 本文內容僅作為醫療衛教知識分享，不涉及任何特定療效宣稱。**任何醫療處置均有其適應症、禁忌症與風險**。實際治療計畫請務必尋求專業醫師親自評估後執行。
```

### 3.5 醫療法合規自查

寫完後逐項確認：

- [ ] **無療效保證**：無「保證治好」「一定有效」「100% 改善」「根治」
- [ ] **無次數承諾**：無「做 X 次就會好」等具體次數保證
- [ ] **無比較廣告**：無「比其他診所更好」「全台最佳」「首選」等比較性宣稱
- [ ] **無具體費用**：無特定治療費用數字或收費區間
- [ ] **有醫療提醒框**：「何時就醫」段落含標準提醒框
- [ ] **有文末醫療聲明**：完整聲明段落
- [ ] **不回答預後**：FAQ 無「幾次會好」的直接承諾
- [ ] **無誤診暗示**：無「A 常被誤診為 B」「容易被誤診」「診斷錯誤」等語句；改用「A 與 B 症狀相似，需透過理學檢查鑑別」
- [ ] **無批評他院或他醫**：無「其他診所」「一般醫師」「傳統治療方向錯誤」「之前的治療沒有針對根本」等任何可被解讀為批評他人執業的句式
- [ ] **無招攬就醫語句**：無「歡迎預約」「立即掛號」「歡迎來診」「歡迎至本院」等招攬行為（醫療法 85 條）；改用「建議由復健科醫師進行評估」
- [ ] **無指導讀者如何提問**：無「不妨在就診時主動說…」「可以告訴醫師你有…症狀」等引導讀者操控診斷方向的句式；保持對醫師專業的信任，只說明何時值得就醫
